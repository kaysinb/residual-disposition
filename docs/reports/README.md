# Gate reports

Write one report per evaluated gate (`gate-1.md`, `gate-2.md`, and so on) and link it from
[decisions.md](../decisions.md). Reference the
[preregistered criteria](../preregistration.md#gate-thresholds) instead of copying them.

Use aggregates only, never raw completions. Run IDs, analysis inputs and scripted figures follow
the [publication evidence contract](../architecture.md#publication-evidence).

Stage 0 has no gate; its measurements are in [stage-0.md](stage-0.md). Stage 1 evaluated
[Gate 1](gate-1.md) (not passed) and [Gate 2](gate-2.md) (passed as written); the stage-1 runs,
incidents and costs are in gate-1.md.
